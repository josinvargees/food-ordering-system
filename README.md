# 🍽️ Food Ordering System

A full-stack food ordering web application built using React,
Spring Boot and MySQL.

## 🚀 Features

- User Login & Registration
- Browse Food Items
- Add Food to Cart
- Update Cart Quantity
- Place Orders
- Order History
- Responsive UI
- REST API Integration

## 🛠️ Technologies

### Frontend
- React.js
- Vite
- Axios
- React Router
- CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL

## 📂 Project Structure

food-ordering-system/
├── frontend/
├── backend/
└── database/

## ⚙️ How to Run

### Backend

1. Open the backend in IntelliJ IDEA.
2. Configure MySQL.
3. Set database credentials.
4. Run the Spring Boot application.

### Frontend

npm install
npm run dev
